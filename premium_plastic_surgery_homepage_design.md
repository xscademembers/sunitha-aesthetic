# Premium Plastic Surgery & Aesthetic Clinic — Homepage Design Specification

## Design Direction

Create a **luxury, editorial, human-designed plastic surgery and aesthetic clinic website**.

The website must feel like a premium private clinic, **not a hospital, medical portal, SaaS dashboard, template, or AI-generated website**.

### Core visual personality

- Elegant
- Sophisticated
- Warm
- Minimal
- Editorial
- Trustworthy
- Feminine but not overly decorative
- Premium without looking flashy
- Medical credibility combined with luxury beauty aesthetics
- Generous whitespace
- Strong typography
- Large, intentional photography
- Subtle motion
- Refined asymmetry
- High-end fashion/editorial art direction

### Strict Color Palette

Use only:

- **Primary Burgundy:** `#9C4A47`
- **White:** `#FFFFFF`
- **Black:** `#000000`

Do not introduce beige, cream, gold, grey, pink, brown, gradients, blue, green, or any other accent color.

Use opacity/tints of these same colors only when necessary.

### Important design rules

Avoid:

- Generic AI-looking layouts
- Excessive cards
- Repeated 3-column grids
- Glassmorphism
- Excessive rounded containers
- Floating blobs
- Gradient backgrounds
- Neon effects
- Overuse of shadows
- Generic medical icons
- Dashboard-style UI
- Stock-photo-heavy appearance
- Too many CTAs competing with each other
- Every section looking structurally identical

The design should use **editorial composition, whitespace, typography, photography, overlapping elements, horizontal movement, and carefully controlled asymmetry** instead of putting everything inside cards.

# Global Design System

## Typography

Use a premium serif + modern sans-serif combination.

### Recommended pairing

**Display / Headings**
- Cormorant Garamond
- Playfair Display
- DM Serif Display

**Body / UI**
- Inter
- Manrope
- Helvetica Neue

Use serif typography for emotional, high-impact statements and the surgeon's name.

Use sans-serif typography for navigation, descriptions, labels, buttons, and supporting information.

### Typography hierarchy

- Hero heading: very large, approximately `72–96px` desktop
- Section heading: `48–64px`
- Large editorial statement: `56–80px`
- Card/service heading: `22–28px`
- Body text: `16–18px`
- Small labels: `11–13px`, uppercase with generous letter spacing

Typography should create most of the visual identity.

# Responsive Design

The design must be genuinely responsive, not simply scaled down.

## Desktop

- Editorial layouts
- Large typography
- Asymmetric image compositions
- Horizontal treatment rails
- Generous whitespace

## Tablet

- Reduce typography
- Preserve editorial layouts where possible
- Convert complex image compositions into simpler arrangements

## Mobile

Prioritize:

1. Hero
2. Surgeon
3. Clinic
4. Treatments
5. Testimonials
6. Google Reviews
7. FAQs
8. Consultation CTA
9. Footer

### Mobile rules

- No horizontal overflow
- No tiny text
- Touch-friendly buttons
- Accordion treatments instead of dense lists
- Horizontal testimonial/treatment scrolling where useful
- Images remain large and visually important
- Maintain generous vertical spacing

---

# Animation & Interaction System

Use subtle, premium motion.

### Page entrance

- Fade + upward movement
- 400–700ms
- Smooth easing

### Images

- Slow reveal
- Slight scale from `1.04` to `1`
- Optional subtle parallax

### Buttons

On hover:

- Burgundy background transition
- Arrow moves slightly
- Underline animation where appropriate

### Treatment accordion

- Smooth height transition
- Image changes with category
- Content fades/slides in

### Navigation

- Compact on scroll
- Smooth transition

### Important

Motion should feel **expensive and intentional**.

Never animate everything.

# Component Philosophy

The website should not be built as:

`section → heading → 3 cards → section → heading → 3 cards`

Instead, intentionally alternate compositions:

1. Full-width hero
2. Editorial surgeon split
3. Asymmetric image gallery
4. Large accordion treatment system
5. Horizontal treatment rail
6. Large video testimonial
7. Editorial review carousel
8. FAQ split layout
9. Full-width consultation CTA
10. Spacious footer

This variation is essential to make the site feel designed by a professional designer.

---

# Accessibility

Ensure:

- Strong text contrast
- Keyboard navigation
- Visible focus states
- Accessible accordion buttons
- Alt text for meaningful images
- Proper heading hierarchy
- Reduced-motion support
- Buttons have clear labels
- Videos do not autoplay with sound

---

# Final Quality Standard

The finished homepage should feel comparable to a **high-end private aesthetic clinic website designed by an experienced creative agency**.

The first impression should communicate:

**“This is a premium, trustworthy clinic where I would feel comfortable booking a consultation.”**

The website should feel:

**Luxury + Medical Expertise + Personal Care + Confidence**

Not:

**Hospital + Template + SaaS + AI-generated UI**

Every section should have a distinct visual rhythm while still belonging to one cohesive brand system.

## Most Important Rule

**Do not try to fill every available space.**

Premium design comes from:

- typography
- whitespace
- photography
- hierarchy
- alignment
- scale
- restraint
- subtle motion
- strong content

The result should look intentionally art-directed rather than automatically generated.
