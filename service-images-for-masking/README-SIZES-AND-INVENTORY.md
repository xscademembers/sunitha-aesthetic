Folder: `service-images-for-masking/`

## Required size for new masked images

Website shows each image in a **4:3** frame (`object-contain`).

| Spec | Value |
|---|---|
| **Preferred export size** | **1440 × 1080 px** (4:3) |
| Alternate (higher res) | **1920 × 1440 px** (4:3) |
| Format | PNG or JPG (JPG quality 90+) |
| Layout | One combined before/after image (side-by-side), same as current |
| Naming | Keep the same filename when you return them (e.g. `01.png`, `02.png`) |

Do **not** use square (1:1) for new exports — older square files still work but get letterboxed on the site.

## How it appears on the website

- Section: **Before & After** on each service page
- Grid: 1 col mobile / 2 cols tablet / 3 cols desktop
- Card aspect: **4:3**
- Image fit: `object-contain` (full image visible, no crop)
